# Chandan Kamisetty — Portfolio Site

A static, independent portfolio site: no database, no framework and no build process.

## Deploy
1. Upload the contents of this folder to Netlify Drop, or connect this folder/repository to Netlify.
2. In Netlify, set project access to **Public**. Private access blocks recruiters and search engines.
3. After publishing, test /, /assets/Chandan-Kamisetty-CV.docx, /robots.txt and /sitemap.xml in an incognito window.
4. If you add a custom domain, replace the three spontaneous-naiad-c3209f.netlify.app references in index.html, robots.txt and sitemap.xml.
