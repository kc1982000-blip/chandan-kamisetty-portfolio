# Chandan Kamisetty — Portfolio Site\n\nA static, independent portfolio site: no database, no framework and no build process.\n\n## Deploy\n1. Connect this repository to Netlify, or upload the repository contents to Netlify Drop.\n2. Keep the Netlify project access set to **Public** so recruiters and search engines can reach it.\n3. After publishing, test the homepage, the inline ATS resume download, /robots.txt and /sitemap.xml in a private browser window.\n4. If you add a custom domain later, replace the three spontaneous-naiad-c3209f.netlify.app references in index.html, robots.txt and sitemap.xml.\n\n## Files\n- `index.html` is self-contained and includes the ATS resume download data inline, avoiding a fragile external download route.\n- `robots.txt`, `sitemap.xml`, `_headers` and `404.html` support search visibility, security and fallback handling.\n- `assets/Chandan-Kamisetty-ATS-Resume.docx` is retained as a downloadable resume copy for repository-based deployments.\n
